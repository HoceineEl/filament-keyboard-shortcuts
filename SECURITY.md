# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.2.x   | Yes       |
| < 0.2   | No        |

## Reporting a vulnerability

Please do not open a public issue. Email **contact@hoceine.com** with a description of the problem, the affected version and, if you can, steps to reproduce it. You can also use "Report a vulnerability" on the Security tab of the GitHub repository.

You will get a reply within 3 working days. Once a fix is ready it is released as a patch version, an advisory is published, and you are credited unless you prefer otherwise.
